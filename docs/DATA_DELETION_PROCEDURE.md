# Data Deletion Procedure

1. Authenticate and verify the requester.
2. Locate account, document metadata and applicable personal-data references.
3. Check financial, tax, audit, dispute and legal retention requirements.
4. Create/retain a privacy request record for accountability.
5. Delete unnecessary personal data and applicable private documents.
6. Where a financial record must remain, minimise or anonymise personal linkage where this preserves accounting integrity.
7. Invalidate the user's active sessions as part of account closure where applicable.
8. Record completion without copying deleted personal data into the audit trail.
9. Communicate the result and any legally required reason for retained data.

Deletion must be deliberate and transactionally safe. A failed storage deletion must not be reported as complete, and a failed database operation must be rolled back.
