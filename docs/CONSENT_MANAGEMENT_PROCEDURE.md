# Consent Management Procedure

## Scope

MandalFinance uses consent only for processing that actually depends on consent. Core account, financial accounting, security and legally required processing must not be represented as optional consent merely to obtain agreement.

## Required evidence

Each consent record contains the authenticated user, purpose, status, notice version, source and timestamps. The current application supports explicit grant and withdrawal for optional analytics and communications purposes.

## Rules

1. Consent must be affirmative and purpose-specific.
2. Do not pre-tick optional consent.
3. Do not bundle unrelated purposes.
4. Record the notice version presented at the decision.
5. Withdrawal must be as easy as granting consent.
6. Withdrawal does not retroactively invalidate processing that was lawful before withdrawal.
7. Application features using optional consent must check the current status before processing.

## Review

Consent purposes and the notice version must be reviewed whenever optional processing changes.
